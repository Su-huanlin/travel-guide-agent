# Trip intake template

Copy into chat or `brief.md` at trip root. Fill unknowns with `TBD`.

```markdown
# Trip brief

## Basics
- Trip name:
- Dates (start–end):
- Nights:
- Party: adults / kids / rooms
- Home city / return city:

## Style
- Priority (rank): photography / comfort / cost / hiking / food
- Max acceptable gate-to-gate drive on a hard day (hours):
- Willing to use internal flights/trains to skip long transfers? yes/no
- Hotel tier: chain mid / upscale / local boutique / camping OK?
- Hard no lodging types:

## Transport
- Arrival airport/station:
- Departure airport/station:
- Self-drive? yes/no
- Same-city return rental or one-way dropoff OK?
- Second driver? yes/no
- Vehicle preference: SUV / sedan / 7-seat max for park roads

## Include / exclude
- Must include:
- Must exclude:
- Soft wants (drop if pace breaks):

## Gear / permits
- Camera bodies/lenses:
- Drone? yes/no (UOM + local rules required)
- Special reservations known (park entry, highway appointment):

## Budget
- Attitude: secondary / soft cap / hard cap
- Soft/hard amount (2 people total) if any:

## Open questions for agent
1.
2.
```

## First agent response after intake

1. Restate constraints in 5–10 bullets (including deletes).  
2. Propose overnight master table only.  
3. Ask for OK / edits before writing full daily guides.
